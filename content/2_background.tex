\begin{enumerate}
    \item 3D Model
    
    After coming up with an idea, the user either creates the 3D model from scratch or downloads one from the various databases available online and optionally modifies it. 
    Creating and modifying a model requires highly domain-specific knowledge and skills.
    While there is a lot of educational content in the form of videos, written tutorials and documentation for every level of expertise easily available, especially for newcomers it takes a lot of practice, effort and time to reach a level where the design will come close to their desired outcome.
    \item Print Setup 
    
    As the next step, they have to choose the printing material (called filament) for different parts, \eg printing the box itself in white PLA and the text in a different color PLA, and set at the very least the temperature according to the materials specifications in case they differ from the presets used. 
    Oftentimes further parameters or presets are needed to determine factors like supports\footnote{\todo definition}, infill, speed and heating bed temperature. % does it make more sense to explain these terms in the text or in footnotes?
    In this case, the green boxes around the closures need to be marked as modifiers to increase the wall loops in the main model for added stability. 
    Furthermore the box is designed to be printed as two separate bodies, one for the top and the bottom each, which means the top including all its text bodies have to be placed on the printing bed accordingly. 
    \item Slicing 
    
    The model then has to be translated into layer-by-layer instructions for the printer. 
    \item Printing 
    
    After inserting the chosen materials into the printer and optionally calibrating, the model can be printed. 
    \item Evaluation
    
    Especially for newcomers and casual makers, the print might not turn out perfect on the first try. 
    Therefore the print has to be evaluated for design flaws or printing errors. 
    This often leads to revisions in the 3D model itself or the print setup, starting a new iteration of the workflow. 
\end{enumerate}

\section{Slicer}

Steps 2 and 3 of the workflow described above, are done with so-called slicer software.
The name originates from its main task of slicing a 3D model into printable layers, since ``the key to how [additive manufacturing]\footnote{\todo explain term `AM'} works is that parts are made by adding material in layers; each layer is a thin cross-section of the part derived from the original CAD data.''[Additive Manufacturing Technologies]
While it does offer some basic functionalities to create 3D models as well, its focus lies in setting up a finished model for printing and translating the data represented as described above into instructions for a specific target printer to follow. \cite{hudson_understanding_2016}

Slicers are capable of importing 3D models in various different representations and transforming them to the slicer's preferred format. 
Visually the model's parts are placed on a virtual representation of the printer's heating bed, which is the surface that a model is printed upon. 
Since printers have different dimension, the heating bed as well as the available height need to be available to the slicer for proper setup. 
Users have the option of setting this up manually, however more commonly the slicer accesses a list of printers, oftentimes from various manufacturers, for the user to select one from. 
These dimensions are important to arrange parts in an efficient way to print, in case the model consists of multiple parts.

The software also provides a selection of generic as well as manufacturer specific filament presets containing specifications such as the filament's name and material, recommended printing nozzle and heating bed temperature, and printing speed. 
From these the user can create their own filament presets, tweaking parameters to accommodate for their own needs to reuse the settings across projects. 
Further printing parameters that need to be frequently changed include quality related parameters (layer height, line width, precision, bridging), parameters regarding the model's strength (wall loops, top and bottom shell thickness, infill amount and type) as well as the type of support and thresholds where supports need to be applied. 

When the model is sufficiently set up, the slicer translates it into layers, described as paths for the printer to follow. 
Due to the nature of this process, the slicer handles projects in two different ways. 
Before slicing, the 3D model needs to be saved as a project including all parameters as defined by the user in a way, so it can be loaded and updated at a later point, independent of the printer to be used. 
For this step, slicers generally use either the open-source format 3MF or a proprietary file format. 
The sliced model file, on the other hand, needs to be specific to one printer ecosystem and is usually saved as gcode or bgcode files. % todo: fact check

There are many different slicers available online nowadays, either general ones or specific to one printer manufacturer. 
Since getting all the settings right for a particular 3D printer can be difficult, some manufacturers prefer to modify one of the open source programs, creating a version for their machines.\cite[p.~58]{horvath_mastering_2018} 
Thus, most of the commonly used slicers today are based on the same code base, derived from an ancestor called Slic3r. 
Due to the similarity in code base and the need to keep these projects open-source\footnote{Slic3r is licensed under the GNU Affero General Public License, version 3, which states that every software using parts of it has to be subject to the same license.}, useful features are oftentimes introduced in one version and then ported to the other ones. 


\section{File Formats used in 3D Printing Context}

There are various different file formats available to represent 3D models in general, however not all are equally appropriate for digital fabrication. 
Hence, the following paragraphs will delve into the three formats used most in 3D printing.

\subsection{STL}

The STL (``STereoLithography'') format has been introduced in the 1980's and since then acquired support by most softwares in use for digital fabrication. 
It is considered to be the most well-known and used mesh file format, even though it has rigorous limitations.
The contents can be either encoded in binary or in ASCII text format, the latter of which is less common, but used for illustration and educational purposes. 
It describe an approximation of the surface geometry in the form of a mesh of triangles, each identified by a unit normal vector as well as three vertices, as seen in \ref{lst:stl_example}.
The normal vector is equal to the length ``1'', however it does not specify whether the dimensions are millimeter, inches or another unit entirely. 
Thus, while the proportions of a model will remain preserved, the overall size depends on the user's knowledge about the model. 
Due to its simplicity, the file does not contain information regarding color, text or other common CAD model attributes.[Additive Manufacturing Technologies, p.~341 ff][3D Printing with Fusion, Chapter 5]

Furthermore, since the specification requires each triangle to share two of its vertices with the triangle adjacent to it, thus creating one continuous solid model, technically there will always be exactly one body in the resulting file. 
For a model comprised of multiple parts, the user therefore has to choose whether to combine all bodies into one or export each body as a separate file.
However, modern slicer software is capable of separating parts into disparate bodies, even if the user chooses to export a multibody model into one file.

\subsection{3MF}

3MF has been developed by the 3MF Consortium, founded by Microsoft, Autodesk, HP, 3D Systems, Prusa Research and several other key players in the field, to create a 3D printing file format that addresses the shortcomings of previous standards (STL, OBJ, AMF).
In particular the possibility for extensions and the support of colors as well as several different 3D model representations were a main factor, making it ideal for additive manufacturing.\cite{rossel_security_2023}

Unlike the other two formats, 3MF not only preserves separate bodies even when exported as a single file making it more user-friendly, it also includes information about the model’s color, material, and textures.

\subsection{Exporting as 3MF}

Unlike the other two formats, 3MF not only preserves separate bodies even when exported as a single file making it more user-friendly, it also includes ``information about the model’s color, material, and textures.''\cite{iancu_about_2018}
Initially when importing a 3mf file containing multiple objects, OrcaSlicer asks the user whether the file should be loaded as a single object with multiple parts instead of considering them as multiple objects similar to the dialog when importing multiple STL or OBJ files at once.

\subsection{Applying Materials}
\label{chap:apply-materials}

``For extrusion-based 3D printing, material properties such as rheology\footnote{\todo explain} or melting temperature are as relevant as machine configurations such as print speed, nozzle geometry, and heating profiles.'' [It’s Not the Shape, It’s the Settings]

Generally, materials can be set using system or user defined presets per object. 
Material settings entail, amongst others, the filament itself, nozzle temperature, general printing speed and cooling settings.
OrcaSlicer actively asks the user, whether they want to save any changes to material parameters they have made, which makes it easy to save either parameters specific to one's printer and filament or even specific to one project while simultaneously keeping default material presets untouched.
When importing a new file or project, OrcaSlicer does apply the first available user preset filament by default. 
More detailed analysis even showed, that a multicolor file will be imported with different filaments assigned consecutively but the user doesn't have any options to map colors to filaments the way it works with OBJ files. 
Furthermore, the last color per colorgroup (more details in the following chapter \ref{chap:3mf}) is assigned to each object which is why even complex models with different colors appear as having one single material in OrcaSlicer. 

\subsection{Applying Settings with and without Presets}
\label{chap:apply-settings}

Settings like the amount of wall loops, infill percentage and pattern, and printing speed for single layers might need to be customized. 
It is possible to save these as presets as well, however only globally, \ie they can only be applied to the entire project, not to specific objects within.
As criticized in the \textit{OrcaSlicer Issue \#7769}\footnote{Copy/paste per-object settings: When planning/building large projects in-slicer it often becomes an extremely tedious task to click all the objects you want a specific set of settings to apply to. The larger the assembly/project you are planning, the easier it is to miss a body and make a mistake. If you "assemble" models together you cannot edit multiple sub-objects across assemblies.\\ \url{https://github.com/SoftFever/OrcaSlicer/issues/7769}}, particularly for projects containing multiple objects, using presets in this case is not a valid option.
